Design File Upscaler

AI-enhance the low-resolution images inside .psd and Affinity .af files. Free, open-source models, running entirely in your browser — your files never leave your computer.

Drop a .psd, .af, .afphoto, .afdesign or image file here or click to choose · PNG / JPG / WebP also accepted

The first run downloads the AI model (5–40 MB, then cached). Large layers at 4× can take several minutes — keep this tab in front. A computer with a decent GPU is much faster.

How it works & limitations

PSD: every pixel layer (and, optionally, embedded smart-object images) is enhanced with an ESRGAN super-resolution model. The whole document is enlarged by the chosen factor, layer positions, masks, vector masks, text and effect sizes are scaled to match, and you download a new layered PSD. Text layers are kept as live text (Photoshop re-renders them when opened).

Affinity (.af / .afphoto / .afdesign): Affinity's format is closed, so the page can't write a new .af file. Instead it finds the images placed inside the document (JPEG/PNG/WebP), enhances them and gives you a ZIP. In Affinity, select each image → Replace Image… in the context toolbar → pick the enhanced file. Size and position stay the same, but the image now has 4–16× more pixels.

Affinity pixel layers (painted or rasterised layers, not placed images) are stored in Affinity's private tile format and can't be read here. Workaround: in Affinity use File → Export → PSD (keep layers), run the PSD through this page, then open the enhanced PSD in Affinity.

AI upscaling adds plausible detail; it cannot recover text or fine details that were never in the image. Check results before printing.

Uses UpscalerJS + TensorFlow.js (MIT), ag-psd (MIT), fzstd and JSZip. No server, no sign-up, no cost.
